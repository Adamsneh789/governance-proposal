# Governance Proposal Contract

A contract that manages the full lifecycle of governance proposals,
including creation, voting status tracking, and execution readiness.

## Key Functions
- `create-proposal` — Submit a new governance proposal
- `set-status` — Update proposal lifecycle state
- `get-proposal` — Retrieve proposal metadata and status
- `list-proposals` — View all active or archived proposals
- `is-approved` — Check if a proposal meets approval conditions

Designed for DAOs, protocol upgrades, treasury actions, and governance workflows.
